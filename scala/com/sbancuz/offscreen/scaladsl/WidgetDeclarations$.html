WidgetDeclarations

com.sbancuz.offscreen.scaladsl.WidgetDeclarations
object WidgetDeclarations

Describes text fields, sliders and other controls before a screen opens. The same declaration can create independent controls in several screens. Declaring it here does not open a window or load Minecraft client classes, so definitions can be prepared in common mod code.
