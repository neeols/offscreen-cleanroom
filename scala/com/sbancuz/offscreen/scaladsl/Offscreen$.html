Offscreen

com.sbancuz.offscreen.scaladsl.Offscreen
object Offscreen

Compact Scala 3 syntax for the complete shared Offscreen button and window APIs.

Import com.sbancuz.offscreen.scaladsl.Offscreen.*. Keep your GUI's own appearance and input code and add just popOut(existingButton)(new MyScreen), or build a new vanilla-looking button with popOut("Open")(new MyScreen).build(42, x, y, 100, 20). A screen expression is evaluated freshly on each click, not while declaring the button. Java builder methods still provide images, tooltips, per-state skins and custom painters. Native Scalar for Scala 3 supplies the optional runtime; Java-only consumers do not load this object.

Window and GUI operations must run on Minecraft's main client thread after initialization. Supply local screens; a server-backed container must use its synchronized factory. Ordinary GUI layout still belongs to your screen.
