openWindow

fun openWindow(title: String, width: Int = 1280, height: Int = 800, screen: () -> Any): Window

Opens and sizes a local desktop window through the shared helper, cleaning partial output if setup fails.

Call after client initialization with Minecraft's primary GL context available. This is synchronous and must not run on a worker or dedicated-server thread. Closing the returned window releases its hosted UI; it does not close the main game. Kotlin's apply can configure the returned window further through the complete Java API.

Return

actual open window owned by the caller

Parameters

title

native desktop title

width

positive logical window width, default 1280

height

positive logical window height, default 800

screen

supplier of a fresh supported local screen

Throws

IllegalArgumentException

if a dimension is not positive

IllegalStateException

if screen adaptation or native-window setup fails

fun <H : HostUI> openWindow(factory: HostUIFactory<H>, screen: () -> Any?): Window?

Opens any supported screen with a caller-supplied adapter, bypassing registry lookup. Keep the returned window on the client thread. All adapter callbacks and cleanup remain with the Java host.

Return

open window, or null if either supplier or adapter returns null

Parameters

factory

adapter factory, receiving the fresh screen object

screen

fresh screen supplier, invoked once
